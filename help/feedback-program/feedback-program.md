## 参与者期望

Adobe反馈计划的参与完全是自愿的，旨在满足各种兴趣、产品和参与级别的需要。 可邀请参与者：

* 评估新功能和测试新兴技术
* 通过调查、基准研究和概念评估分享反馈
* 参与研究活动，包括可用性测试
* 在战略会议中直接与Adobe产品团队互动

销售机会因产品领域、地区、客户个人资料和计划可用性等因素而异，并非所有参与者都会被邀请参加每个销售机会。 您的反馈可帮助Adobe改进产品、优先考虑未来的投资，并提供更好的客户体验。

## 常见问题解答

+++ 谁可以参与？

欢迎任何人，无论其工作级别如何，参加。 我们重视来自拥有所有经验级别和所有相关工作职能的个人反馈。 公司可以注册参加计划的代表人数没有限制。 请注意，雇员的参与由参与公司全权决定。

+++

+++ 参与率需要支付任何费用吗？

参与其中不会产生任何金钱成本。

+++

+++ 我随时可以离开该项目吗？

是的。 虽然我们很乐意听到您的反馈，但我们知道情况会发生变化。 参与完全自愿，如有需要，您可以随时选择退出。

+++

+++ 是否存在保密要求？

是的。 计划的参与者将收到Adobe的机密信息，不得在计划外共享或讨论该信息。

+++
