# Adobe支持语音助手 — 非工作时间和周末支持（日本）

>[!NOTE]
>
>本页介绍可在日本工作时间后和周末期间提供基于电话(IVR)支持的AI语音助手，此时实时座席不可用。 有关工作时间内提交的一般案例，请参阅标准的[Adobe客户支持体验](/help/adobe-support-tools-guide/adobe-customer-support-experience.md)文档。

## 概述

当您需要超出正常Adobe支持工作时间（日本的晚上、晚上或周末）的帮助时，AI语音助手可通过电话为您提供帮助。 会说流利的日语，就像您在现场支持代理时一样，助手会理解您的请求并立即帮助您。

这意味着您无需等到下一个工作日再查看您的案例状态或标记紧急问题之类的事情 — 您可以随时获得支持。

>[!TIP]
>
>如果问题导致重大中断或严重业务影响，助理可以立即提升您的案例优先级 — 请参阅下面的“将案例优先级提高至P1”。

## 语音助手可以执行的操作

AI语音助手支持以下功能：

* 用日语理解和回答
* 立即检查案例状态
* 接收未决案例的最新更新
* 在适当时将案例优先级提升到P1
* 向Adobe支持部门请求回调
* 捕获对技术问题的响应并自动将其添加到案例注释

### 用日语理解和回答

自然地用日语和助手说话，就像和现场支持代理说话一样。 无需按电话按键或使用特定的关键词 — 只需用自己的话解释您需要什么，助理就能用对话方式理解和回答。

### 立即检查案例状态

如果您有未结的支持案例，请向助理请求更新。 它会立即查看并告诉您事情的进展。

### 接收未决案例的最新更新

该助理可以共享您的案例中记录的最新备注或进度，因此您无需等待回调或电子邮件即可确切了解迄今为止发生的情况。

### 将案例优先级提高至P1

如果您的问题很严重（如重大系统故障或严重影响业务的某个事件），助理会发现问题并将您的案例优先级提高至P1（严重）优先级，因此即使工作时间以外，助理也会立即予以关注。

>[!NOTE]
>
>将优先级提升到P1会立即通知支持团队。 您会收到针对关键问题的回调，这与Adobe的标准P1响应过程保持一致。

### 向Adobe支持部门请求回调

如果您希望与技术支持工程师交谈，或者您的问题需要更详细的帮助，请咨询该助手，然后由Adobe支持人员为您安排回电。

### 捕获对技术问题的响应并自动将其添加到案例注释

如果助理询问您技术问题，以便更好地了解您的问题（例如，错误消息、重现步骤或发生问题时您正在做什么），您的答案会自动保存到案例备注中。 这意味着，您以后不必重复执行上述操作；下一个接手您案例的支持工程师已拥有此信息。

## 示例对话

为了帮助您了解呼叫的方式，下面提供了几个交换示例：

### 检查案例状态

| 扬声器 | 日语 |
|--- |--- |
| 客户 | ケース番号12345の状況を教えてください. |
| 语音助手 | かしこまりました。ケース12345を確認しています…現在、エンジニアが調査中です。最新の更新は本日午後3時に記録されています. |

### 升级到P1

| 扬声器 | 日语 |
|--- |--- |
| 客户 | 本番環境がダウンしていて、業務に大きな影響が出ています. |
| 语音助手 | に引き上げます。担当チームにすぐ通知いたします P1. |

### 请求回调

| 扬声器 | 日语 |
|--- |--- |
| 客户 | 担当者から電話で詳しく話したいです. |
| 语音助手 | 承知しました。コールバックのリクエストを登録しました。担当エンジニアより折り返しご連絡いたします. |

>[!NOTE]
>
>如果问题导致生产系统中断或严重中断，助理会优先为您提供升级或回调选项以立即获得帮助。

## 限制

虽然AI语音助手可以处理许多常见的支持需求，但它当前无法执行某些操作。 对于这些情况，助理将引导您向人力支持工程师学习。

* **无法访问已验证帐户之外的案例** — 您需要验证您的身份或案例详细信息，助理才能共享任何案例信息

* **无法解决呼叫的复杂技术问题** — 助理可以收集信息并将其记录到您的案例中，但深入的技术故障排除由支持工程师处理

* **无法保证立即回调计时** — 回调请求将根据案例优先级进行优先级排序（例如，P1案例的处理速度最快），但确切的响应时间可能有所不同

* **无法处理日语以外的语言** — 该助理专门针对在此非工作时间/周末服务期间的日语对话而设计

* **无法进行产品配置更改** — 例如，修改Adobe产品或环境中的设置

* **无法方便转接至人工代理**

>[!NOTE]
>
>对于助理功能之外的任何内容，系统都将无缝指导您向Adobe支持工程师请求回调。
